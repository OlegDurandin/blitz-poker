# Blitz Poker 3.1 — UI/UX

Изменения подготовлены 6 ноября 2026 по `BLITZ-POKER-3.1-UX-UI-SPEC.md` и трём визуальным концептам. Макеты использованы как направление оформления. Карты, суммы и результаты взяты из движка/серверного состояния; покерные правила и сетевой протокол не изменены.

## Что изменилось

- Общие `SeatView`, `TableArena` и `LegalActions` для Solo, Duel и стола на 3–4 места. Свои карты снизу, соперники по краям сукна, единый статус места, D/SB/BB и таймер у действующего игрока.
- Лобби с местами, хозяином, ботами, приглашением, копированием кода и объяснением недоступного старта. Возврат в оставленную комнату с главной.
- Контекстное окно ставки с пресетами, ручным вводом и подтверждением. Фокус удерживается внутри диалога; повторная отправка online-действия блокируется до ответа/нового состояния.
- Вскрытие с номерами и цветами участников на картах лучших пятёрок, реальными выплатами и раскрываемой информацией об основном/побочных банках. Чужие скрытые карты после фолда не раскрываются.
- Главная с быстрым стартом и друзьями, без номера сборки в production. Настройки звука/вибрации, история текущей раздачи, reduced motion, safe areas и адаптация окна ставки к visual viewport.

## Как посмотреть

[Галерея до/после](preview/index.html) содержит главную, лобби, столы на 2/3/4 места, вскрытие и окно ставки. Это статические HTML-снимки компонентов, а не работающая сетевая игра. В галерее можно выбрать версию и ширины; кнопка «Все экраны» запускает проверку горизонтальной геометрии 42 вариантов.

Для полной проверки галереи через HTTP из корня проекта:

```sh
python3 -m http.server 5180 --bind 127.0.0.1 --directory docs/ui-3.1/preview
```

Затем открыть `http://127.0.0.1:5180/`. Для живого интерфейса используется обычный `npm run dev` в `web`.

Текущие снимки можно пересоздать (baseline «до» сохраняется отдельно):

```sh
cd web
BLITZ_UI_OUTPUT=../docs/ui-3.1/preview npx vitest run src/qa/ui.test.tsx
```

## Проверки

- Production-сборка WASM, TypeScript и Vite проходит.
- `cargo test --release --workspace`: 139 тестов прошли, включая интеграционные PvP-сценарии и 20 000 решений ботов. Дублирующий медленный debug-прогон остановлен после успешного release-прогона.
- Frontend: 67 тестов прошли; 1 генератор HTML-снимков пропускается без `BLITZ_UI_OUTPUT`.
- В Chrome проверены 7 экранов × 6 ширин: 320, 360, 375, 390, 430, 768 px. Горизонтального скролла и обрезания кнопок, board, банка и стеков не обнаружено. Этот тест не доказывает отсутствие всех вертикальных перекрытий.
- В работающем браузере проверены создание стола с ботами, выбор рейза, ручной ввод 60, подтверждение и переход хода с обновлением стека.
- UI-тесты проверяют 2/3/4 места, единственного активного игрока, статусы, legal actions, скрытые карты после фолда, многоцветные/номерные маркеры, реальные выплаты side pots и защиту от двойного клика в обоих сетевых форматах.

## Границы проверки

Реальные VK и Telegram WebView на iOS/Android, системная увеличенная типографика, экранная клавиатура и FPS на слабом Android ещё требуют проверки на устройствах. Приглашения между VK и Telegram в этой локальной сессии не отправлялись. Редизайн не опубликован.

Промежуточная подсказка комбинации скрыта: текущий интерфейс движка не предоставляет проверенный evaluator для неё. Побочные банки показываются на вскрытии, когда сервер возвращает pots/eligible/winners; отдельные выплаты внутри каждого банка не вычисляются на клиенте. Общие выплаты участникам показаны из awarded. Растровые портреты и текстуры из концептов не добавлялись: используются существующие аватары, SVG и CSS.

В рабочем дереве также сохранены предшествующие исправления подключения/создания комнаты и пользовательский `.env.example`; они не относятся к визуальному редизайну.
